## 2. Checker changes (`scripts/atlas_quote_check.py`)

Two small fixes to the `number-not-in-quote` heuristic, both false positives that the repaired quotes would otherwise have tripped; the `verbatim / segments / near / missing` classification is untouched.

1. The thousands-separator rule glued a space-separated table row into one number (`667.9 451.8` read as `667.9451.8`), so a quote that lists a column of decimals could not support any value but the first. A space is now a thousands separator only when no decimal precedes it and no decimal point follows the three digits (`1 366 m` still reads 1366).
2. A value stored in metres whose quote gives feet or miles ("2,150 feet underground" for 655 m, "2.4 miles" for 3862 m) was flagged. Feet, inches, yards, miles and nautical miles are now converted (1 % tolerance, since such figures are rounded).

Effect: number flags in maps/geometry/sites 43 -> 5 (unmodified checker on the repaired data: 24). The 5 that remain are listed in section 7.
