# HEP Atlas v1.0 — release report (specification §108)

Released 2026-09-18 from branch `hep-atlas-v1`, merged to `main` and deployed
to `hep-graph.vercel.app/atlas`. Every number below is either generated by a
script named next to it or taken from a report file under
`docs/atlas-worklog/`; where something was not done, this report says so.

## 2. Architecture

- **Ontology.** `docs/HEP_ATLAS_ONTOLOGY.md` v0.2 with amendments A1–A24 at
  the top overriding the body. New this release: A23 (a detector site may
  rest on an admitted campus-grade point, which warns instead of failing, is
  drawn dashed and labelled "Approximate location") and A24 (technology
  classes for helioscopes, light-shining-through-wall, lumped-element
  resonators, cryogenic phonon detectors, skipper CCDs, spherical proportional
  counters, radiochemical detectors and magnetic spectrometers).
- **Rendering stack.** Vanilla JavaScript on vendored Globe.gl. New this
  release: marker clustering with semantic zoom (facilities far, sites medium,
  institutions in collaboration mode), cluster expansion that always
  terminates (below a fixed altitude clustering is off for the tier), a
  filters panel (status, topic, facility kind, experiment kind, region,
  era) composing with the timeline and round-tripping through the URL, arcs
  capped and off by default above 150 institutions, a loading state and an
  offline/error state with retry, lazy loading of provenance and sources on
  disclosure open, and the approximate-location marker style.
- **Data pipeline.** One JSON file per entity under `data/atlas/` →
  `hepgraph.atlas.validate` (contract enforcement; new rules
  `coordinate-kind-approximate`, `collapsed-history`, A16 keyword for first
  detections, terminal ordering restricted to lifecycle intervals) →
  `hepgraph.atlas.build` (stripped bundles plus lazy `provenance.json` and
  `sources.json`; coordinates carry `approximate: true` when confidence is
  not verified) → `static/atlas/generated/`. The server sends strong ETags and
  `Cache-Control: public, max-age=0, must-revalidate` for every atlas file
  and answers `If-None-Match` with 304.

## 4. Research categories covered

Colliders (23 incl. LHC forward experiments, LEP, Tevatron, SLAC, HERA,
B-factories); accelerator neutrinos (15 incl. KARMEN, LSND, OPERA, DONUT);
atmospheric neutrinos (3); reactor neutrinos (5); solar and radiochemical
neutrinos (6); neutrino mass (2) and neutrinoless double beta decay (9);
astrophysical neutrinos (13); direct dark matter (17, noble-liquid and
cryogenic/low-threshold); axions and ALPs (7); muon precision and rare
processes (6); fixed target, rare kaons and long-lived particles (10); CEvNS
(4); cosmic rays (2) and gamma rays (6); heavy ions (3, plus ALICE under
colliders). Deliberately not covered and stated in the worklogs: the CERN SPS
heavy-ion programme (NA49/NA50/NA60/NA61), Bevalac and AGS heavy-ion
experiments, and every programme outside the specification's lists (the
coverage red team that would have inventoried those was not run — §9).

## 5. Timeline

Range 1943–2026 with future `planned` intervals dimmed as "assumed ongoing"
past the build date. State at a year is derived from lifecycle intervals only
(A3); 28 records whose whole life had been folded into a single terminal
interval (so ALEPH read "completed" in 1990) were split into an operating
interval and a terminal event, and the validator now warns on the class.
Experiment status distribution at the build date: 54 completed, 43 active, 10
construction, 7 commissioning, 6 shutdown (LHC Long Shutdown 3), 5 proposed,
4 upgrade, 1 approved, 1 decommissioned.

## 6. Collaboration mode

Three collaborations have geographic institution membership (DUNE, ATLAS,
CMS; 659 rows, evidence classes shown in the UI wording of A19). Institution
dots cluster at every zoom and arcs are off by default above 150
institutions; the frontend's coordinate-reading bug that had drawn no
institutions at all against the real bundle was fixed this release. Rosters
for the other flagships were not built (§9).

## 7. HEP Graph integration

Twelve people linked by INSPIRE author id, each attached to a collaboration on
its own evidence class; the institution → person → HEP Graph handoff is
unchanged. HEP Graph's routes and tests are untouched; the atlas's static
assets have their own rate-limit bucket.

## 8. Data quality

- **Independent verification.** Every wave-3 domain was verified by an agent
  other than its researcher (`docs/atlas-worklog/VERIFY_*.md`, 15 reports;
  two by the orchestrator after their agents were stopped). Roughly 330
  sources re-fetched; 14 P0, 51 P1 and 28 P2 findings; all P0/P1 fixed.
- **Issues found.** The dominant defect was paraphrased or spliced "verbatim"
  quotes (values right, evidence text wrong); wrong values were rare (CRESST
  thresholds, a Mu2e length, the JUNO PMT count, four stale statuses, one
  over-typed 2.7σ "first detection", one press-release-sourced result).
  Classes and fixes: `docs/atlas-worklog/INTEGRATION_ISSUES.md` rows 38–54.
- **Uncertain identities.** None new; no person was added this release.
- **Missing historical data.** Collaboration formation dates for most wave-3
  collaborations (null with notes); hall-specific coordinates for ~30 sites
  (admitted approximate under A23); H.E.S.S. II inauguration; exact phase
  boundaries for several 0νββ programmes; membership counts where no
  collaboration page states them.
- **Source conflicts recorded:** 106 rows across the research worklogs.

## 10. Performance

- Bundles: `atlas.json` 1.42 MB (over the 400 KB pilot budget, which predates
  wave 3), `provenance.json` 2.67 MB and `sources.json` 1.38 MB loaded lazily
  on first disclosure open, `institutions.json` 538 KB, total generated
  8.5 MB uncompressed; compression and ETag revalidation on every asset.
- Panel open with Sources collapsed: 0 provenance/sources requests (was 2.2 MB
  eager); warm reload: 12 of 20 requests answered 304 (`REVIEW_performance.md`
  closure section).
- Markers: 19 at the default far zoom (7 clusters over 48 facilities), 64
  after one expansion; collaboration mode 20–31 clustered institution markers
  for CMS/ATLAS instead of 177–203.
- FPS: measured only under a software rasteriser in headless Chromium, 7.5–9
  → 12.5–15.5 fps for CMS/ATLAS with arcs on (a 1.5–1.9× improvement); the
  60 fps target on real hardware was not measured this release and is not
  claimed.
- Accessibility (`docs/atlas-worklog/REVIEW_accessibility.md`): axe-core 0 violations across 16 scans; three P1s fixed (muted-text and border contrast below WCAG AA, uncertain markers had no non-colour encoding, Escape did not close panels or return focus); one P2 left documented (legend glyph for "uncertain" differs from the marker hatch).
- Link check: 1,485 of 1,486 sources checked; none dead (11 bot-blocked 403s, 6 × 406, one unresponsive PDF mirror listed for review).

## 11. Remaining coverage

Per `docs/HEP_ATLAS_COVERAGE.md`: 125 of 131 experiments lack institution
membership; 78 lack any result; 93 lack a technical document; 13 lack a dated
history on some axis. The next release should start with the coverage red
team, the flagship rosters, and re-fetching every quote in the domains where
verifiers sampled rather than exhausted the sources.
