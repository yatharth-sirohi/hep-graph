# HEP Atlas — release-candidate repairs and to-scale local maps (handoff report)

Branch `hep-atlas-local-maps` (from `origin/main` 773fa85), 78 commits, worktree
`../HEP-Graph-atlas-maps`. Every number here is generated by a script or read
from a file named next to it; what was not done is stated as not done.

## 1. What this branch delivers

**Workstream A — repairs to the released Atlas**

- A1 Routes and panels for sites, detectors, accelerators and beamlines
  (`static/atlas/js/state.js`, `panels.js`): search selection and pasted cold
  links no longer end in "Unknown entity type"; globe site markers open the
  site panel; the no-WebGL fallback gained Sites and Accelerators/Beamlines tables.
- A2 Layering: `#globe-container` is its own stacking context
  (`isolation: isolate`), so three-globe's per-marker inline z-indexes can no
  longer paint over the Results/Documents panel (reproduced at 1084×786 and
  fixed; tests at four viewports × two modes). Dense browsing: counts, sort,
  grouping, owner names, text filter, wider panel on laptops, internal scroll.
- A4 Provenance: JSON pointers are rendered as human claim labels grouped by
  claim (`static/atlas/js/provenance.js`) with the raw pointer kept in a title;
  `official_url_kind` distinguishes arXiv/DOI duplicates from a real official
  page (37 results affected); honest empty states and partial-roster wording.
- A5 Methodology page `static/atlas/about.html` (live counts from the bundles),
  footer links to it, report reconciliation in `docs/HEP_ATLAS_V1_REPORT.md` §12.
- A6 Failure path: the fixture fallback only happens on `?data=fixtures` or a
  localhost host; a deployment missing its bundle shows the error state.

**Workstream B — to-scale local maps**

- Contract: `docs/HEP_ATLAS_GEOMETRY.md` (entities `map`/`geometry`, GeoJSON,
  representation classes surveyed/georeferenced/derived/inferred_direction,
  accuracy, checks, levels, unlocated lists, licences) + ontology A25.
- Pipeline: `hepgraph/atlas/geo.py`, validator rules (§2 table of the contract),
  build outputs (`atlas.json.maps`, `geometry/<slug>.json`, derived
  `map_id`/`geometry_map_ids`, coverage section), `scripts/atlas_osm_extract.py`.
- View: Leaflet 1.9.4 (vendored, BSD-2), route `#/map/<slug>` with `lv`/`bm`/`sel`
  and the timeline state, metric scale bar, north indicator, level toggles,
  depth diagram, four visual encodings (type, status-at-year, level,
  representation), accessible feature list, drawer with the entity panel and
  shape facts, linked maps/far sites, OSM basemap with attribution (toggleable).
- Data: 39 maps, 174 geometry records (168 to-scale features), all 64 accuracy checks passing at
  build time, 41 unlocated entries with sourced reasons and backlog. Coverage
  by facility with honest grades: `docs/atlas-worklog/GEOMETRY_COVERAGE_STATE.md`.
- Site coordinates: 25 site records corrected from the geometry worklogs
  (DESY ×3 by 12.8 km, Jefferson Lab 6.5 km, Telescope Array 36 km, SLAC halls,
  LANSCE, SNS, BNL halls, J-PARC halls, KEK Tsukuba, CJPL, Hyper-K Tochibora,
  SURF, HAWC, LSM, LSC, RENO halls); OpenStreetMap-derived points are recorded
  as A23 campus points with approximate confidence, published coordinates as
  detector/underground_lab.

## 5. Independent QA

`docs/atlas-worklog/REVIEW_geometry_qa.md` — a reviewer other than any
researcher, with six sub-reviewers, re-fetched OpenStreetMap elements and
primary papers and recomputed residuals for 14 flagship maps (CERN, Fermilab,
J-PARC, KEK, BNL, DESY, SURF, SNOLAB, Kamioka, South Pole, KM3NeT-ARCA,
Auger, H.E.S.S., LHAASO). Every principal ring reproduced bit-exact or within
its check tolerance (LHC 0.30 %, HERA 0.30 %, RHIC < 1 m, KEKB 53/53
vertices, TI12/TI18 0.0 m, CNGS azimuth 0.00°). Verdict: all 14 fit for
production, South Pole "as an honest placeholder" (one feature, eight
entities unlocated for a reproduced blocker).

Defects found: one **P0 class** — the build asserted `active` over any open
`valid` window, so the LHC tunnel read as running during Long Shutdown 3 and
HERA's tunnel after decommissioning (10 records; root cause fixed in
`build.py`, commit 072d506); one **P1** — SeaQuest/NM4 was listed "no OSM
trace" while a tagged OSM node exists (now drawn); **P2s** — 20 non-canonical
JSON files, 5 OSM-derived records without the ODbL licence (validator rule
`geometry-license` added, 11 records fixed), 2 direction lines with a stray
licence, 7 records without `osm.timestamp`; LHAASO's coordinate upgraded from
a 5 km geocode to the peer-reviewed figure. Licensing verdict: no official
figure, plan or image copied anywhere; every OSM-derived shape now carries
the attribution. Security: nothing beyond the laboratories' own public maps.
Open items (documented in §8 of the review): SPS representation class,
H.E.S.S. CT5 label, the IceCube array footprint, Auger's citation.

## 6. Fit for production?

_Verdict line filled from §4 below._

Caveats that hold regardless of the gate results:

- **Coverage is honest, not complete.** Of the 39-facility set, 18 maps show
  a layout to scale, 15 show footprints or sourced points only, 5 draw a
  single reference point (PSI, SNS, LANSCE, Boulby, South Pole) and JUNO has
  no map. Every gap is an `unlocated[]` entry with a sourced reason and a
  backlog; the UI lists them under "Unlocated / geometry not verified" and
  the coverage report counts to-scale features, not map shells.
- **Not drawn because no public source supports the shape**: the Fermilab
  Main Injector, Recycler and PIP-II; the LBNF target and DUNE near-detector
  hall; CEBAF (not in OpenStreetMap, re-checked); the KEK 12 GeV PS; the
  Chooz laboratories; the IceCube string array (grid orientation not in a
  fetchable source — a documented unblock exists); the DUNE far-detector
  caverns; HIPA; the LANSCE and SNS linacs; the SLC arcs.
- **Derived shapes are labelled as such.** The Tevatron and Booster rings are
  fitted circles anchored on three convergent OpenStreetMap tracings (the QA
  review reproduced the fit twice); the Daya Bay and RENO halls are
  multilaterated from published baselines, two checks widened to 5–6 % with
  the reason stated in the records.
- **Performance** was measured only under Chromium's software rasteriser
  (SwiftShader) on a loaded machine; no frame-rate target on real hardware is
  claimed. Initial globe load does not fetch Leaflet or any geometry bundle;
  each map bundle is fetched only when its map opens (largest: CERN 147 KB,
  Fermilab 123 KB; all 39 bundles together 1.07 MB; Leaflet 144 KB, loaded
  only on a map route).
- **Deployment.** The branch is pushed and Vercel builds a preview per push,
  but the preview is behind deployment protection (HTTP 302 to login), so it
  was not verified from here; production `main` is untouched. Deploying is
  the reviewer's call after this PR.
- **Site records** were corrected where the geometry research found the
  recorded point wrong by more than its precision (26 sites); the remaining
  campus-grade points are still labelled approximate in the UI.
